# Outils MEP pour SolidWorks

Complément **gratuit** pour SolidWorks : un onglet **Outils MEP** pour les traitements par lot.

| Bouton | Ce qu'il fait |
|---|---|
| **Mise en plan Exporteur** | PDF / DWG / DXF de nombreuses mises en plan, format de feuille, échelle 1:1, filtres sur les propriétés |
| **PDF et QTY Traitement** | Quantités (QTY) écrites dans les plans d'un assemblage, PDF et PDF fusionné |
| **Format Conversion Pièce** | STEP, IGES, Parasolid, STL, CATIA de nombreuses pièces |
| **Propriétés par lot** | Ajouter, modifier ou supprimer des propriétés sur tout un dossier |

## Télécharger

👉 **[Dernière version](https://github.com/Ernix79/OutilsMEP/releases/latest)**

Deux fichiers au choix :

- **`OutilsMEP-Setup.exe`** : le plus simple. Ferme SolidWorks, lance le fichier, puis clique **Installer**.
- **`OutilsMEP-<version>.zip`** : si l'antivirus bloque le .exe. Clic droit sur le zip > Propriétés > **Débloquer**, puis **Extraire tout**, puis double-clic sur **`Installer.cmd`**.

**Nécessaire :** Windows 10 ou 11, SolidWorks, .NET Framework 4.8 (déjà présent sur Windows 10 et 11).

## Mises à jour

Une fois Outils MEP installé, plus besoin de retélécharger quoi que ce soit :

**Paramètres Windows > Applications > Outils MEP pour SolidWorks > Modifier**, puis **Mettre à jour en ligne**.

Le programme vérifie aussi tout seul, à l'ouverture, s'il existe une nouvelle version. Tes réglages sont conservés.
